# 果蝇遗传规律 · 合成实验日志

这是一次**只依据 EaseReport 方法与其可选 CSS 原语**制作的跨领域示例。没有借用其他领域报告 skill，也没有将原有两列评分骨架强行套在遗传计数上；生物学和统计资料仅用于核对事实与方法。

[打开可下载 HTML](../../demos/drosophila-mendel.html) · [合成数据](data.json) · [来源](sources.json) · [验收](../../docs/mendel-verification.json)

所有后代计数与日志均为合成记录，没有实施生物实验。模拟按待展示的理论抽样，**不能用来独立验证该理论**；p 值不构成“证明孟德尔定律”的证据。

## 三组设计

| 组别 | 教学杂交 | 期望表型比例 | 合格可判读 N |
|---|---|---|---:|
| 单因子 F2 | Aa × Aa | 3:1 | 300 |
| 双因子 F2 | AaBb × AaBb | 9:3:3:1 | 496 |
| 双因子测交 | AaBb 雌 × aabb 雄 | 1:1:1:1 | 264 |

A/a 为 vg 翅型的教学等位型，B/b 为 e 体色的教学等位型。FlyBase 定位分别为 2R 和 3R；本例采用完全显性、非连锁的常染色体教学模型，不把同名基因的所有等位型或真实品系都当作同一遗传模式。真实品系编号未虚构。

固定随机种子为 `20261015`，逐只按理论概率抽样，不按 p 值重抽、调参或筛瓶。难判读数、质控异常、待登记瓶和小样本瓶为预先设置的教学情景。P/F1/F2 时间轴使用虚拟 D0–D35，不代表现实日期。

## 推荐走查

1. 点击组别柱图，在三个遗传问题之间切换。
2. 选择培养瓶，核对其计数、分母与日志；`D-05` 保留排除前计数，`D-06` 保留缺测。
3. 点击一个表型，只收紧明细；观察 χ² 和 N 保持完整类别的范围。
4. 展开理论配子组合、逐瓶记录和逐日日志，核对模型与来源。
5. 选择 `T-04`：N=12，每类期望数为 3；近似 p 值不显示。
6. 导出筛选后的 CSV 与包含分析范围的视图 JSON；分页不截断导出。

默认双因子 F2 的观察计数为 `292,85,89,30`，理论期望为 `279,93,93,31`，χ²≈1.498、df=3、近似 p≈0.683。这只是该合成样本的理论对照，不是生物学验证结论。

## 重新构建

Python 3.10+ 标准库即可：

```sh
python examples/drosophila-mendel/build_report.py
```

从固定 seed 重新生成记录并构建：

```sh
python examples/drosophila-mendel/build_report.py --regenerate-data
```

`model.py` 枚举配子组合推导理论概率，并计算固定概率的 Pearson χ²。df=1/3 的上尾概率由 `erfc` 与伽马递推的闭式表达式计算，未依赖 SciPy。期望频数不足 5 时只展示描述性偏差，不报告该近似 p 值。

统计预计算结果与原始记录在构建时互相核对，不一致会拒绝构建。培养瓶标识、QC、缺失与分离类别保持显式；这个领域适配器和模板留在本示例内，不进入通用 skill 的强制规则。

本例构建器只接受显式合成记录。转用真实实验资料时，应另外建立实际来源、品系核验、观察和 QC 规则、统计假设及相应适配；不要靠修改标签把模拟结果称为真实结果。
