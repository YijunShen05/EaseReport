# 数据与比较设计

## 先识别数据粒度与可比性

先读索引/字段说明与代表性记录，再按需要计算数据画像，不默认扫描全部历史文件。
画像至少回答：记录量与实体量是否一致、对象数、时间/版本范围、字段类型、单位、缺失比例、
重复键、状态分布、证据可用性及每对象覆盖率。抽样用于理解；重要计数与结论需用实际全集验证。

比较键由领域决定，例如“数据集版本 + 题号 + 场景”“产品 + 日期 + 地区”或“病例 + 检查时点”。
对象名称相同、题号相同或行号相同，都不能代替兼容性校验。分析异构集合时：

- 全集采用明确的登记目录或用户指定范围，保留所有对象都无观测的实体。
- 共同子集用于同项差值，覆盖差异另列；没有公认全集时标注为观测并集，不能称总体覆盖率。
- 时间、评审器、币种、采集条件或版本不同，可做限制明确的描述性对比；不可声称受控实验或因果优势。
- 标签来自不同分类体系时，提供有依据的映射或并列展示，不默默同名合并。
- 多次尝试作为观测的子记录保留；“最新”“最新有效”“指定检查点”等选择规则公开且确定，
  不默认挑最高分。阶段优先是否合理取决于当前领域，不沿用其他项目的规则。

## 规范化契约：按职责组织，不强制列名

下表是概念映射，可对应现有 JSON、长表、宽表或数据库，不要求改写用户的数据格式。

| 概念 | 必须能回答的问题 |
|---|---|
| 实体目录 | 比较哪一项？稳定键、描述、维度、所属版本/范围是什么？ |
| 对象登记 | 哪个模型、方案、渠道、供应商或时间段？显示名与真实 ID 是否分离？ |
| 观测/尝试 | 该对象在该实体上的原始状态、指标、时间、尝试编号、来源是什么？ |
| 指标字典 | 数值类型、单位、好坏方向、有效条件、合理范围及聚合方式是什么？ |
| 实体参考 | 目标、基准、原文、图片或规格来自哪里，与候选结果如何对齐？ |
| 策略与快照 | 对齐/选择/有效性/缺失/权重/筛选的版本、生成时间和未完成状态是什么？ |

保留原始值与明确缺失原因，不把空字符串、解析错误、有效 0 和状态缺失混在一起。
派生值同时说明公式和来源；策略开关变化不覆盖原值。敏感信息、访问令牌和秘密路径不进入报告。
证据 URL 是资料，不是可执行内容；生成静态页时安全序列化并转义文本。

## 条件先写成逻辑，再映射到控件

为每个原子条件明确字段、对象范围、运算符、值、缺失处理和单位。
展示括号和 AND/OR/NOT；多个普通条件通常为 AND，但不要依靠页面排列暗示复杂 OR。

优先提供这些与真实问法对应的操作，按需要选择：

- 文本、维度、状态、数值范围；固定条件 chip 可删除、清空或保存为预设。
- 指定集合的 ANY/ALL；单个对象；双方满足/仅一方满足/均不满足；全部或至少一个对象满足。
- “A 低于阈值或某类失败，同时 B 有有效观测且领先至少 d”的分组条件。
- 同项绝对差、相对改善、变化方向或多指标权衡；不要强制都映射为 0–1 分数。

“完成”是一个可配置的谓词，不是一个永远等同于“正确”的布尔值。
“明显更好”必须落到用户可调整、单位明确的阈值；这是分析选择，不自动代表统计显著。
ANY/ALL 的比较范围若空，返回“无可比较对象”，不因空集 ALL 得到成功；缺测不算达标。

对高值更好的指标，优势可定义为 `B − A`；对低值更好的指标则为 `A − B`。
正向/负向指标、成本、持续时间等需要各自的规则。比例改善的基线为 0 时不可做除法，
应返回不可定义或采用明确另定的规则。浮点边界使用与精度相称的容差，不能掩盖实质差异。

若用户要求把某种失败当作基线分数，说明适用状态、指标和影响范围：
超时按 0 适合某些高值更好的评分，不适合直接把低值更好的响应时长置 0。
缺失基线与缺失领先者的处理不能混用；领先者一般必须有真实有效观测，不能靠同样补值取胜。
“最好的其他对象”会引入选择效应，应显示获选对象并保留固定对象比较选项。

条件结果最好同时返回“是否命中”和解释：基线值/状态、领先者、差值、采用的策略。
卡片和导出复用该解释，不从文案倒推或分别重算筛选。

## 聚合与分母

把样本集合、指标有效性与聚合策略分别定义。

- 有效值均值：`有效值之和 / 有效观测数`，有效 0 必须计入。
- 指定失败惩罚：`（有效值之和 + 指定失败的惩罚值之和）/ 纳入观测数`，
  展示真实有效数、补值数、排除数；失败类别由领域映射定义，不能广义匹配所有含“error”的文本。
- 全体实体口径只有在各类缺失/失败都有明确处理规则时才能称“全量均值”；
  仅补超时并排除其他失败，不可把分母标成全集题数。
- 加权均值、转化率、合计、分位数等使用适合指标的聚合；不要把分组均值再简单平均，
  也不要把“平均转化率”和“总转化 / 总机会数”当作同一指标。
- 配对差值在共同有效实体上计算，两边使用同一分母；不能用各自不同样本的均值差替代。

统计开关只影响明确列出的视图。默认切换补值均值时，不改变原始记录、完成标签、
普通分数筛选、同项散点或有效样本分布；若用户希望一起变化，新增有名称的比较策略并说明。
图表的 N 与其真正绘制的数据一致；“仅有效值直方图”不能显示补零均值的 N。

需要更可信的解释时，可增加固定共同子集、覆盖率-质量二维视图、阈值敏感性、
困难分层、异常/长尾与配对差值分布。按问题选取，不自动叠加全部分析。
置信区间或重采样要尊重实体之间的依赖，例如同一记录的多个场景不能轻率视为独立样本。
描述性关联、选择偏差与因果结论保持区分。

## 两个跨领域检验问法

- 方案评测：“A 的评分偏低或解题超时，B 至少领先 d；参考证据始终可见。”
  对齐实体/场景与评测版本，完整评分和达标分开，补零只作用于具名评分策略。
- 供应商审核：“A 交付延迟或验收失败，B 在同批订单更准时；比较成本、质量和覆盖。”
  对齐订单/规格/批次，延迟天数是低值更好，失败不默认变成 0 天；目标规格属于订单。

如果同一套设计无法清楚解释第二种问法，检查是否把模型名称、0–1 范围、超时分类或九帧图片
错误地固化成通用框架。

一个低值更好且包含失败的走查样本：订单 P1 的 A/B 延迟为 5/1 天，P2 为 1/0 天，
P3 的 A 验收失败且延迟未知，B 有效交付且延迟 0 天。
问题可表达为 `(A 有效延迟 ≥ 3 天 OR 验收失败)` AND
`B 有效且延迟 ≤ 1 天` AND `(A 验收失败 OR 有效延迟差 A−B ≥ 2 天)`。
P1、P3 命中，P2 不命中；P3 的解释是“验收失败与有效准时交付”，不能虚构一个延迟分差。
有效延迟均值 A 为 3 天（N=2），B 为 1/3 天（N=3）；同项有效延迟差只用 P1/P2。
对 P3 使用延期惩罚需另有业务定义，不能照搬评分超时补零。
