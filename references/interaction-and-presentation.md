# 交互与呈现设计

## 根据判断路径安排信息

从“范围与可信度 → 总览 → 条件与对比 → 个案证据”组织页面，布局不必照搬固定组件。
进入页面后用户应能回答：这是什么数据、哪些对象被比较、当前在看哪些样本、数字为何变化。

常见可选结构：

- 页首：标题、数据范围/版本、快照时间、关键口径、进行中/兼容性提示。
- 对象卡片：覆盖率、质量指标与分母，显示开关、只看此对象、恢复全部。
- 筛选区：常用维度与范围，少量问题导向预设；复杂条件渐进展开。
- 条件结果区：有解释的交集/差集卡片、当前命中数与有效/排除样本数。
- 对比区：共同子集统计、趋势/分布/差值或多指标权衡等与问题相关的图。
- 个案区：简洁摘要卡片，展开后才加载细项、来源、异常原因和证据。

不要为了“丰富交互”把所有字段变成控件或给每个指标造图。
高频动作可见，低频说明折叠；对短报告，筛选和卡片可能就足够。

## 明确状态的四个维度

1. 可见对象：哪些对象在卡片、图和证据列里显示。
2. 对比范围：A/B、固定基线、任一其他或全部其他、登记集合或可见集合。
3. 样本条件：搜索、范围、状态、嵌套逻辑、交集/差集与排序。
4. 聚合策略：有效值、补值、加权、共同子集等。

隐藏对象不能偷偷移出固定比较范围；只有控件明确写“所有显示对象”时才随显示集合变化。
保存/导出时保留这四种状态，避免复现时只记住几个数值输入框。
避免用“全部”同时代表全集、当前条件下样本和当前页。

联动采用单一状态和分析结果：

- 明确基础条件集合与进一步的交集集合，统计卡片要标出计数所在层级。
- 交集卡片最好给出基础条件下各类数量，使当前选中项不会让其他卡片全部变成 0。
- 多维 faceted counts 可选；若采用“除本维外的当前条件”计数，所有同类控件保持一致。
- 图表点/柱可触发筛选或定位个案，并提供清除动作，不能悄悄替换其他条件。
- 命中数、均值、有效分母和分页随着状态同步更新；改筛选回到第一页。
- 排序与分页只改变呈现，不能影响聚合全集；并列分数提供稳定的次级排序。
- 空结果说明当前条件并提供撤销或清空，不留下上次结果的图表。

范围输入应说明单位与边界；对无界、对数或负值指标不要套用 0–1。
高级条件以可读表达式或分组控件呈现，区分 AND/OR，拒绝自比较、无效值与歧义。
新增预设要说明是否叠加旧条件；不要让用户无法理解为什么示例与宣传的题数不同。

## 富交互卡片：摘要清楚，证据不遮蔽

实体卡片的折叠态通常包含标识、关键维度、各对象的指标/状态、命中原因和参考入口。
展开态按需要包含：分项、观测来源、尝试选择、时间/费用、失败原因、判定理由、原始证据。
原始值、补值与阈值判定分别标记，不用数值 0 掩盖失败。

参考和候选使用实体级对齐，缺候选显示占位及缺失原因。
不同领域采用不同证据交互：

- 图像/视频：相同时刻或视角并列、同步切换、放大、可选差异层/滑动对照。
- 文本：源文与结果分栏、差异突出、可选长度/语义说明；长文折叠，避免全屏堆叠。
- 表格/业务记录：关键字段对照与差异标记，订单/来源链接，不必转成截图。
- 时间序列：对齐时间窗与采样，展示中断/无观测区域，而非画成连续真实曲线。

不要把“参考来自某一成功对象”当作实现捷径。若多个参考版本共存，显式选择实体的对应版本。
媒体按需加载，可共享内容哈希缓存；可移植包内只带必要证据，不复制整个私有源目录。

## 视觉系统服务于比较

为页面建立少量一致的字体、间距、表面、边框、强调色和状态标记。
对象颜色跨图表/卡片保持一致；状态另用文本/图标说明，不只靠红绿颜色。
数值使用易比较的排版，名称、单位、N、原始/派生标签位置稳定。
采用清晰层级和留白；暗/亮主题按用户需要，不能用重阴影与装饰盖过数据。

少数对象可同时出现；很多对象时提供搜索选择、固定参考/基线、分组或横向比较区，
不要将几十列缩成无法阅读的小图。移动/窄窗可堆叠证据，保持同项上下文和固定基线身份。
表格可横向滚动，但页面整体不应因超长 ID 或控件固定宽度发生横向溢出。
折叠、对话框和过滤按钮有可理解的名称、键盘操作与可见焦点。

图表随指标选择解释轴、好坏方向和分母。用一致色阶和可见的零点/截断提示，
不要用不同坐标范围伪造领先程度。关系复杂才可视化；单一事实或几个数值用表格即可。

## 可复现与可交付

按需求考虑：可保存的命名筛选、分享/恢复当前视图、条件摘要、策略版本、当前筛选导出、
两份快照差异和新/旧状态迁移。URL 仅记录非敏感状态，不能将私密查询值或完整数据写到链接中。

导出明确区分：原始字段、用于当前分析的派生字段、缺失原因、筛选条件与聚合策略。
CSV 的缺失与 0 可区分；防止可能作为公式执行的非数值文本，不只处理引号。

依据体量选分页、虚拟列表、图表聚合、输入防抖、索引或 worker。
避免每次按键重新读取来源、重算重任务或加载全部媒体；页面的统计仍基于完整命中集合。
无需后台的 HTML 不引入隐含联网依赖；需要大规模服务查询时明确交付与权限变化。
本地预览只开放所需资产，跨项目/跨目录链接需检查可移植性与授权，不能暴露秘密或整个数据根目录。


## 可选的编辑式分析风格

用户需要简洁直观的阅读路径时，可采用[编辑式分析风格](editorial-analytical-style.md)。
它把清晰的章节关系、留白、少量高价值控件与“图表选择 → 下层项目 → 明细证据”组合起来，
而不是规定颜色、领域或组件总数。已有数据策略和本页四维状态继续生效。
