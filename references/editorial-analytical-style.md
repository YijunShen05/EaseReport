# 编辑式分析报告：可选视觉与交互方案

当任务需要“先看清结论，再比较，再追查个案”，或用户选择克制、留白充分、分析型的页面时，
使用此方案。它提供可迁移的版式语法，不规定领域、颜色、统计策略、图表类型或页面模块数量。
用户已有视觉系统或任务适合其他结构时，保留其选择。不要把此方案升级为所有 HTML 的唯一外观。

## 迁移的是关系，不是源报告的内容

- **主次关系**：首屏一个核心发现或问题，旁边放最有解释力的规模/状态，少量补充指标从属。
  没有可靠主指标时用简短摘要替代大数字；不要为了排版创造 KPI。
- **编辑式秩序**：限制正文行宽，靠标题、段距、细分隔线和稳定对齐组织长页。
  卡片用于同级对象或独立证据，不把每段文字装进圆角框。少用阴影和装饰性渐变。
- **排版节奏**：标题清晰但不挤压内容，正文舒展，口径/来源小一层但仍可读。
  数字用等宽数字，技术标识可用等宽字体，中文长名称允许断行；不规定某个英文字体。
- **有意的不对称**：宽屏可用摘要/规模、分布/解读的不同列宽；窄屏改成有序纵排。
  左右位置表达阅读顺序，不隐含统计配对或因果关系。
- **证据的深度**：结论层 → 口径与比较 → 分布 → 明细/证据。
  这是按判断需求选择的顺序，简单任务可只保留其中两层，不固定八节报告。
- **主题独立**：颜色、字体、密度、宽度和断点是可替换 tokens。状态含义同时用文本或符号表达；
  更换主题后，层级与操作仍应成立。不要把某次品牌色、logo 或时间写进通用资源。

## 简洁直观优先于功能数量

读者应能用一句话说出本节在回答什么。复杂成立条件可以压成少量并列关系，旁边只放必要解释；
长推导或证据留到展开层。不固定必须三个条件，条件数量由真实逻辑决定，也不为排版删掉必要条件。

图表选择应有领域含义：点击一个上层分组，更新下层分类及明细；再点击具体项目，直接定位其结果。
这是“从看到到行动”的捷径，不要求用户回到远处的下拉框重输同一条件。保留选中态、当前条件摘要
和直接清除入口。下层选择与上层不兼容时按明确规则清除，并让结果状态可见；不要静默制造空结果。

先呈现少数高价值动作，复杂条件只在真实问法需要时展开。可见范围与统计口径仍按原 skill 分离，
图表联动不能偷偷改写比较基线或聚合规则。

## 可选资产如何使用

- [editorial-analytical.css](../assets/editorial-analytical.css)：排版、节距、布局与响应式原语。
  可整体引用或按现有框架映射其关系，不要求迁移 CSS 类名。`--report-*` 控制主题与密度。
- [editorial-analytical.html](../assets/editorial-analytical.html)：小型离线交互参考骨架。
  展示条件选择 → 分类柱图 → 明细展开 → 同状态导出；不是所有报告的通用分析引擎。
- [build_editorial_example.py](../scripts/build_editorial_example.py)：从显式配置生成单文件示例。
  只读取传入 JSON 与本 skill 的资产，不读取生产数据、联网或自动发布。
- [配置说明](editorial-example-contract.md)：示例适配层的字段、支持范围和不支持的复杂分析。

```sh
python scripts/build_editorial_example.py --data examples/release-quality.json --out /tmp/release-report.html
python scripts/build_editorial_example.py --data examples/supplier-delivery.json --out /tmp/supplier-report.html
```

两份数据都是明确标注的合成演示。一个比较发布前后成功率（高值更好），一个比较供应方案的
延迟天数（低值更好，含失败、缺失及有效零）。它们用于验证迁移，不提供行业结论。
已有 React/Vue/其他报告保持其技术栈；借用视觉语法及状态关系即可，不必使用此骨架。

## 延续源报告的交互节奏

1. **先总览，再收紧**：保留当前筛选说明、命中量与有效分母，让用户知道何时看的是全集或子集。
2. **选择可见、撤销直接**：图表选中态、筛选值与明细联动；再次选择或“清除”能取消条件。
   图表是控件时用可聚焦按钮和文字名称，而不只绑定鼠标事件。
3. **共享分析结果**：图表、计数、配对摘要、表格与导出从同一过滤结果派生；
   分页只切视图，不截断统计或 CSV。切条件重置/夹紧页码，不保留失效的旧图。
4. **细节原位展开**：摘要行保持紧凑；展开时给出原始值、有效性、来源和为何没有差值。
   缺失不补成 0，失败不借排版变成普通成功值。
5. **来源可追查、状态可携带**：证据链接与来源说明贴近结论；导出当前选择时带入口径/条件。
   视图快照可用于复现，不把查询值悄悄写入外部 URL 或自动传送。

更复杂的可见对象/比较范围/样本条件/聚合策略，继续按原 skill 的四维状态设计。
小骨架只展示固定一对对象、一至两个分类维度和一个可选配对指标；不把这个演示限制变成 skill 限制。

## 适配与验收

- 字段、单位、好坏方向、零/缺失、来源及配对条件由领域配置提供；CSS 不决定统计含义。
- 无共同有效观测时显示“无同项有效值”，不输出 0 改善；不配对时不显示配对差值。
- 长标签、长 ID、空筛选、少量记录和手机排版都能正常阅读。表格内部可滚动，整页不溢出。
- 检查键盘焦点、展开状态、减少动画、导出与命中集合一致，以及单文件是否真正离线。
- 新增持久规则应能解释两个不同领域；仅属于当前数据的模块留在配置或项目适配层。
